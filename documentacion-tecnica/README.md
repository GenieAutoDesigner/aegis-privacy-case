# Documentación técnica

| Archivo | Qué es |
|---|---|
| `AEGIS_V7_Informe_Validacion_Mecanica.md` | Informe de validación de la V7, con los defectos detectados |
| `AEGIS_V3_Memoria_Tecnica_FINAL.md` | Memoria técnica de la V3: arquitectura, tabla cinemática, envolvente y verificaciones sobre el CAD |
| `AEGIS_V3_Parametros_FINAL.csv` | Parámetros del modelo V3 (separador `;`) |
| `especificacion/AEGIS_Memoria_Boceto.pdf` | Especificación de ingeniería de partida (requisitos) |
| `especificacion/AEGIS_Mecanismos_y_Piezas.pdf` | Especificación detallada de módulos y piezas. Incluye las instrucciones con las que se generó el CAD asistido por IA |
| `especificacion/AEGIS_Arquitectura_Mecanica_V1.pdf` | Resumen de la arquitectura mecánica V1 |
| `historico/` | Memorias, parámetros e informes de fases anteriores, ya superadas |

Las verificaciones de estos documentos (interferencias, holguras) se hicieron **sobre el CAD**, no sobre prototipos físicos. No equivalen a una validación funcional. El estado real está en `docs/estado-del-proyecto.md`.
